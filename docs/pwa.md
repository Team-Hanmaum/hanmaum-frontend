# PWA 설치

운영 주소는 **https://hanmaum.site/**다. 설치 앱 이름은 **한마음**, 시작 주소·범위는 `/`, 표시 모드는 `standalone`이다. 온라인 사용을 전제로 하며 서비스 워커·오프라인 캐시·푸시 알림은 제공하지 않는다.

## 설치 안내

| 환경                            | 동작                                            |
| ------------------------------- | ----------------------------------------------- |
| 설치 이벤트를 제공하는 브라우저 | **한마음 설치하기** → 브라우저 설치 창에서 확인 |
| iOS Safari                      | 공유 → 홈 화면에 추가 → 추가 절차 안내          |
| 설치 이벤트가 없는 브라우저     | 해당 브라우저 메뉴에서 설치하는 방법 안내       |

모바일의 공간 선택·기본 탭에서는 안내를 자동으로 표시한다. 통합 시작·로그인 화면에서는 로그인을 방해하지 않도록 자동으로 열지 않는다. 입력 중이거나 다른 모달이 열려 있으면 미루며, 작성·검토·탈퇴 하위 화면에서도 자동으로 열지 않는다. **전체 → 한마음 설치**에서 수동으로 다시 열 수 있다.

## 숨김과 설치 감지

- 닫기·확인: 같은 탭에서 자동 안내를 숨긴다.
- 다시 보지 않기: 해당 브라우저에 저장한다. 수동 설치 메뉴는 계속 사용할 수 있다.
- 설치 앱으로 실행 중이거나 설치가 확인된 경우: 설치 안내와 메뉴를 숨긴다.
- 브라우저에서 설치가 감지되면 공간 선택·기본 탭에 **이미 설치되어 있어요** 배너를 표시한다. 닫으면 같은 탭에서 숨긴다.
- 설치 감지가 미지원·실패한 경우: 설치 여부를 단정하지 않고 기존 안내를 유지한다. iOS도 기존 안내를 사용한다.

## 설정과 확인

[manifest.webmanifest](../public/manifest.webmanifest)의 `related_applications.id`는 **https://hanmaum.site/**를 사용한다. 아이콘은 `public/icons/`, Apple 메타 정보는 [index.html](../index.html), 설치 판별은 [getInstalledPwa.ts](../src/lib/pwa/getInstalledPwa.ts)에서 관리한다.

배포 후 Android Chrome·iOS Safari 실제 기기에서 설치·앱 실행·아이콘·안전 영역·외부 링크 복귀를 확인한다. 설치 감지 지원 브라우저에서는 이미 설치된 앱의 배너와 같은 탭의 닫기 유지도 확인한다. 로컬·Preview의 감지 결과를 운영 도메인의 설치 여부로 간주하지 않는다.
